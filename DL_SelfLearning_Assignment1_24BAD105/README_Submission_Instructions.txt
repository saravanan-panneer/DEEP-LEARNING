HOW TO RUN IN GOOGLE COLAB
1. Open https://colab.research.google.com/
2. Choose File > Upload notebook and upload the .ipynb file.
3. Choose Runtime > Run all. The first code cell installs required packages.
4. Allow the pretrained BERT model to download. This needs an internet connection.
5. Verify every section has output, especially nearest-word similarity, FastText OOV, BERT contextual cosine and PCA plot.
6. Choose File > Save a copy in Drive. After running, download the notebook with outputs.
7. Download word2vec_pca_visualization.png, vectors.tsv and metadata.tsv from the Colab Files panel if you need them separately.
8. Open the report in Word and replace all [Paste actual output] and [Insert screenshot ...] placeholders with your own run results. Keep the report's conclusions consistent with your actual outputs.
